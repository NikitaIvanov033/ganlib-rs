# ganlib-rs

High-performance Rust framework for reproducible evolutionary search and optimization. Core of the **ganlib** ecosystem.

The goal of this project is to provide a fast, reliable computational core for genetic algorithm experiments that strictly preserves results across runs.

## 🌐 Ecosystem

* **[ganlib-rs](https://github.com)** — High-performance genetic algorithm core written in Rust *(this repository)*.
* **[ganlib-pg](https://github.com)** — PostgreSQL database schema, migrations, and storage layer.
* **[ganlib-py](https://github.com)** — Legacy Python prototype and analytics scripts *(Archived)*.
